`words.txt`: the words players may guess in Code Word (4 to 7 letters). It is the public-domain ENABLE word list
(enable1.txt), filtered to 4–7 lowercase letters, plus every Code Word answer and a few modern tech words ENABLE
lacks (email, emoji, chatbot, ...). The answers themselves are kept out of this public repo, in
`../private/codeword-terms.json` on the owner's Mac (git-ignored) and in the deployed Worker.
