A laptop with 16GB of RAM and >20 GB of disk space is preferred for this course. 

## All SEED Labs:
Access all SEED labs from: [link](https://seedsecuritylabs.org/Labs_20.04/).

## Option 1: Setup SEED VM on Virtualbox:
This option does not work for MacBook M chips. Install SEED VM lab environment on your own laptop: [tutorial](https://github.com/seed-labs/seed-labs/blob/master/manuals/vm/seedvm-manual.md). 

## Option 2: Setup SEED VM on Google Cloud Platform:
This is prefered for MacBooks that are using M chips. A GCP setup guide can be found on Canvas.
